Rule 9. Comments say why. The code says what. Git says when. A comment is only worth its upkeep when it tells the reader something the code can't: a reason, a constraint, a non-obvious consequence.

Four kinds of comment to delete

  1. Narration restates the code. Delete it.
  2. History ("previously…", "we used to…", "changed in PR…") belongs in the commit message. Delete it.
  3. Section markers ("# 2. Build the batch") are a sign the function should be split into named steps. Extract a method instead (chapter 2).
  4. Commented-out code is in git. Delete it.

Comments worth writing

# Sleep to a running deadline, not "interval - elapsed": the latter drifts
# by one step's overhead per tick and the stream slowly falls behind real time.
deadline += self.interval
sleep_until(deadline)

# The model reads `latest_input` without copying, so replace the dict
# rather than updating it in place while a step may be running.
session.latest_input = dict(value)

# Must run on the thread that created the CUDA context (driver restriction).
self.encoder.flush()

Each one explains a reason or a constraint that the next person would otherwise rediscover the hard way.

Docstrings

Write them for contracts, not for every function

A public function or class whose behaviour isn't obvious from its name and signature gets a docstring. A private helper called next_batch() that returns dict[str, dict] doesn't need one.

Lead with one sentence

The first line says what it does, in the imperative or as a noun phrase. Then, only if needed: what can go wrong, what the caller must guarantee, what's surprising.

def join(self, session_id: str, context: dict) -> bool:
    """Admit a session. Returns False if the model is at capacity.

    Joining an id that's already present is a no-op and returns True.
    """

Plain text, not documents

No markdown bold, no headings, no tables, no links to design documents, no section references. A docstring is read in an editor tooltip; if it needs a table, the design belongs in a doc and the docstring should be one line.
